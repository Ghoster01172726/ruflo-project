# Warehouse Sort — чеклист настройки в Unity Editor

Код и структура папок уже готовы. Этот файл — пошаговая инструкция, что нужно
сделать руками мышкой в Unity Editor, когда ты его откроешь. Иди по пунктам
сверху вниз, ничего не пропускай.

## 0. Открыть проект

1. Открой Unity Hub → **Add** (или **Open**) → выбери именно эту папку
   (`UnityGame`, ту, где лежит папка `Assets`).
2. Если Unity Hub предложит создать новый проект — выбери шаблон **3D (Core)**,
   укажи в качестве Location именно эту папку. Unity сама подтянет уже
   существующие `Assets/Scripts`, `Assets/Prefabs`, `Assets/Materials`,
   `Assets/Scenes` и три готовых скрипта.
3. Дождись, пока Unity закончит импорт (прогресс-бар внизу окна).

## 1. Сцена

- [ ] Открой сцену `Assets/Scenes/SampleScene` (Unity создаёт её автоматически
      в новом 3D-проекте). Если её нет — `File → New Scene → Basic (Built-in)`,
      сохрани как `Assets/Scenes/SampleScene`.
- [ ] Убедись, что на сцене уже есть `Main Camera` и `Directional Light`
      (они создаются по умолчанию — трогать не нужно).

## 2. Пол склада

- [ ] `GameObject → 3D Object → Plane`, переименуй в `Floor`.
- [ ] Position: `(0, 0, 0)`. Плоскость размером 10×10 юнитов — этого хватит
      для MVP.

## 3. Префаб посылки (Package)

Это шаблон, который `PackageSpawner` будет клонировать.

1. [ ] `GameObject → 3D Object → Cube`, переименуй в `Package`.
2. [ ] Масштаб (Scale) можно оставить `(1, 1, 1)` или уменьшить до `(0.5, 0.5, 0.5)`
       — как больше нравится визуально.
3. [ ] В инспекторе нажми **Add Component** → найди **Rigidbody**.
   - [ ] Поставь галочку **Is Kinematic** = true (объект не будет падать
         и не будет толкаться физикой — им управляет только скрипт).
   - [ ] Сними галочку **Use Gravity** (или оставь — при Is Kinematic=true
         гравитация всё равно не действует, но для ясности можно снять).
   - Это нужно, чтобы срабатывали триггеры (`OnTriggerEnter`) у зон сортировки,
     когда мы двигаем посылку вручную через `transform.position`.
4. [ ] Убедись, что на кубе остался **Box Collider** (он есть у Cube по
       умолчанию — просто не удаляй его).
5. [ ] Add Component → **PackagePickup** (наш скрипт).
   - Категорию и цвет назначать вручную не нужно — их проставит
     `PackageSpawner` в момент спавна.
6. [ ] Перетащи объект `Package` из иерархии (Hierarchy) в папку
       `Assets/Prefabs` в окне Project — так создастся Prefab-файл.
7. [ ] После того как в Project появился префаб `Package`, **удали объект
       `Package` со сцены** (из Hierarchy) — он нам там больше не нужен,
       нужен только сам файл префаба, который будет клонировать спавнер.

## 4. Спавнер посылок

1. [ ] `GameObject → Create Empty`, переименуй в `PackageSpawner`.
2. [ ] Position, например, `(-4, 1, 0)` — левый край сцены, чуть приподнято.
3. [ ] Add Component → **PackageSpawner** (наш скрипт).
4. [ ] Создай точку спавна: `GameObject → Create Empty`, переименуй в
       `SpawnPoint`, перетащи его **внутрь** `PackageSpawner` в Hierarchy
       (сделай дочерним объектом), Position оставь `(0, 0, 0)` относительно
       родителя.
5. [ ] Выдели `PackageSpawner`, в инспекторе у компонента `PackageSpawner`
       заполни поля:
   - **Package Prefab** → перетащи туда префаб `Package` из `Assets/Prefabs`.
   - **Spawn Point** → перетащи туда объект `SpawnPoint` (дочерний, шаг выше).
   - **Spawn Interval** → оставь `3`, или поставь своё число секунд.

## 5. Зоны сортировки

Нужно создать **три** зоны — по одной на каждую категорию
(`Fragile`, `Normal`, `Heavy`). Повтори эти шаги трижды.

1. [ ] `GameObject → 3D Object → Cube`, переименуй, например, в
       `SortingZone_Fragile`.
2. [ ] Сделай его плоским ковриком: Scale `(2, 0.1, 2)`, Position — где
       удобно на полу (например, `(3, 0.05, -2)` для первой зоны, и разнеси
       остальные две по сцене, чтобы не пересекались).
3. [ ] На компоненте **Box Collider** поставь галочку **Is Trigger** = true.
       Это обязательно — без неё `OnTriggerEnter` не сработает.
4. [ ] Add Component → **SortingZone** (наш скрипт).
5. [ ] В инспекторе у `SortingZone` выбери в выпадающем списке
       **Accepted Category** нужное значение (`Fragile` / `Normal` / `Heavy`
       — соответственно имени объекта).
6. [ ] (Необязательно) Add Component → **Audio Source**:
   - Перетащи в поле **AudioClip** любой короткий звук (можно взять из
     `Window → Asset Store` или своих файлов), снимите галочку **Play On
     Awake**, чтобы звук не проигрывался сразу при старте сцены.
   - В инспекторе `SortingZone` перетащи этот `Audio Source` в поле
     **Feedback Audio**.
7. [ ] Повтори шаги 1–6 для `SortingZone_Normal` и `SortingZone_Heavy`,
       каждый раз выставляя свою категорию в **Accepted Category**.

## 6. Материалы (опционально, для красоты)

Скрипты сами красят посылки в цвет через код (`Renderer.material.color`),
поэтому отдельные `.mat`-файлы для посылок не обязательны. Но для пола и зон
можно сделать простые материалы, чтобы отличать зоны на глаз ещё до фидбека:

- [ ] `Assets/Materials → Create → Material`, назови `Mat_Floor`, задай
      серый цвет, перетащи на `Floor`.
- [ ] Аналогично можно создать `Mat_ZoneDefault` и назначить на зоны (скрипт
      всё равно временно перекрасит зону в зелёный при попадании нужной
      посылки, а потом вернёт этот исходный цвет).

## 7. Камера

- [ ] Выдели `Main Camera`, выставь Position/Rotation так, чтобы видеть и
      точку спавна, и все три зоны сверху-сбоку (например, Position
      `(0, 8, -6)`, Rotation `(50, 0, 0)` — угол сверху вниз, как в
      Papers Please).

## 8. Проверка (Play Mode)

- [ ] Нажми **Play** вверху редактора.
- [ ] Раз в `Spawn Interval` секунд у `SpawnPoint` должна появляться новая
      посылка случайного цвета (жёлтый = Fragile, белый = Normal,
      красный = Heavy).
- [ ] Кликни по посылке левой кнопкой мыши — она должна "прилипнуть" к
      курсору и двигаться за ним по горизонтали.
- [ ] Подведи её к нужной зоне и кликни ещё раз, чтобы отпустить (или просто
      довези её так, чтобы она зашла в зону, — триггер сработает сам, как
      только коллайдеры пересекутся).
- [ ] При правильной сортировке зона должна на полсекунды вспыхнуть зелёным
      и посылка исчезнет. При неправильной — ничего страшного не происходит,
      можно поднять её и отнести в другую зону.

## 9. Если что-то не работает

- Посылка не поднимается кликом → проверь, что на `Package`-префабе есть
  `Box Collider` и скрипт `PackagePickup`, а на сцене есть камера с тегом
  `MainCamera` (у `Main Camera` он стоит по умолчанию).
- Зона не реагирует на посылку → проверь галочку **Is Trigger** на коллайдере
  зоны и галочку **Is Kinematic** на `Rigidbody` посылки.
- Посылки не спавнятся → проверь, что в `PackageSpawner` заполнено поле
  **Package Prefab** (иначе в консоли будет предупреждение об этом).
